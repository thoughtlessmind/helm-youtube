# New UI Implementation Plan

> **For agentic workers:** Use superpowers:subagent-driven-development. One agent per task below; each owns
> a disjoint set of files. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the canvas design (popup + on-page surfaces) for the 17 v2 features and delete the old UI
(header menu, floating buttons, old shadow panels, old popup).

**Architecture:** Popup = Svelte 5 pages driven by the catalog + storage + a popup↔tab message bridge.
On youtube.com every surface mounts into an open shadow root placed in a YouTube slot (action row,
player controls, chip bar, right column), styled only with YouTube's `--yt-sys-color-baseline--*`
tokens via one shared CSS kit (`lib/yt/ui.ts`). Stateful in-page UI (queue panel, dialogs, note card)
may be Svelte components mounted into those shadow roots (`<svelte:options css="injected" />` puts the
component CSS inside the shadow root); simple bits are plain DOM. Native `<dialog>.showModal()` and the
Popover API (`popover="auto"`) give top-layer, Esc and light-dismiss for free.

**Tech Stack:** WXT 0.20, Svelte 5, TypeScript, MV3. No new runtime deps except a local DM Sans font
for the popup (`@fontsource-variable/dm-sans`).

**Spec:** `features-v2.md` (feature list, Global queue / Focus / SponsorBlock / Volume boost specs,
"Cross-cutting work" surface table) + design canvas
`/tmp/cc/youtube-pro/canvas-snapshot-2026-10-13/project/*.dc.html` (byte-identical to the live
artifact on 2026-10-13) + token briefs `/tmp/cc/youtube-pro/mockup-agent-brief-v2.md` and
`/tmp/cc/youtube-pro/popup-agent-brief.md`. Handoff: `/tmp/cc/youtube-pro/handoff-implement-ui-2026-10-13.md`.

## Global Constraints

- Read `CLAUDE.md` first. Performance rules are hard: exactly one MutationObserver (`ctx.observer`),
  SPA routes via `ctx.navigation.onNavigate`, no polling `location.href`, no polyfills/lodash.
- No floating (`position: fixed`) buttons/panels on youtube.com. No extension branding on youtube.com.
  Exceptions that are YouTube-native: the bottom-left toast, popovers/dialogs in the top layer.
- On youtube.com use only `var(--yt-sys-color-baseline--*)` tokens (see `lib/yt/theme.ts`), Roboto
  (inherited), YouTube sizes. Board px on youtube.com boards ÷ 0.8916 = real CSS px
  (12.5→14, 11→12, 32→36, radius 11→12). Popup boards are 1:1 (380×600).
- Popup: DM Sans; dark `#0B0B0F` / light `#FAFAFB` via `prefers-color-scheme`; accent `#F97316`
  (exact tokens = the `THEMES` const in each popup board). No accent setting.
- Port the boards' markup/CSS/copy/states/keyboard behaviour; don't port the `.dc` runtime. Copy the
  user reads comes verbatim from the boards.
- Accessibility (ui-ux-pro-max rules): real buttons/inputs, `aria-label` on icon buttons,
  `aria-expanded` on menu triggers, `role=menu`/`menuitem(checkbox)`, `role=status` toasts,
  visible `:focus-visible`, every drag has a keyboard alternative, `prefers-reduced-motion` respected.
- Storage via wxt `storage` only. Prefs/flags/config → `sync:`; bulky data → `local:ytpro:*`;
  player tab → `session:ytpro:player-tab`.
- Third-party fetches only via `fetchJson()` (SW proxy, `ALLOWED_HOSTS`).
- Every disabled feature costs nothing: no listeners, no DOM. Every `setup()` teardown removes all
  DOM it added and every listener.
- No features beyond the boards + `features-v2.md`. Don't add settings the Settings board doesn't show.
- Commits: `git add <new files>` then `git commit -m "<one line>" -- <your paths>` (commit ONLY your
  own paths — other agents share the tree). Never `git add -A`, never a `Co-Authored-By` trailer.
  If `.git/index.lock` exists, wait 2 s and retry.
- Verification per agent: `npm run check` must show 0 errors **in your files** (other agents' files
  may be mid-edit). Do NOT run `npm run build`/`npm run dev` (shared `.output/`); the lead builds and
  browser-tests after each wave.

## Review Focus

1. YouTube re-renders a slot (SPA nav, theater toggle, chip bar rebuild) → our host is removed or
   duplicated. Expected: exactly one host per surface after any navigation; re-inserted via
   `ctx.observer.onChange`, never duplicated (`getElementById` guard).
2. Light theme (`html:not([dark])`) and true-black. Expected: every on-page surface reads correctly —
   no hard-coded dark hexes.
3. Feature toggled off from the popup while its UI is open (popover/dialog/panel). Expected: all of
   it disappears and keyboard/ended listeners are gone.
4. Two YouTube tabs open. Expected: only the player tab shows the queue panel / auto-advances; the
   other tab can add (toast) and the popup shows "Also playing in another tab".
5. Missing data: no queue, no watch history, no transcript, SponsorBlock 404, channel id not yet
   rendered. Expected: the surface hides or shows its empty state; nothing throws.
